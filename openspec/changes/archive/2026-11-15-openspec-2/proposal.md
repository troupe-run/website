# Proposal

## Why

OpenSpec 2.0.0 (released 2026-11-11) is now the version installed locally, while this repository's OpenSpec files
were generated by 1.14.3 (#116). 2.0 moves the skills to `.agents/skills/`, links them from tool folders such as
`.claude/skills/`, and removes the `/opsx:*` slash commands. `openspec update` deletes the old files, so the
repository and the names it tells people to type have to move together. troupe-run/troupe#423 does the same for
troupe.

## What Changes

- **Regenerate the OpenSpec files with 2.0.0.** Run `openspec update` and commit exactly what it writes, with no hand
  edits. Its dry run lists 25 changes:
  - adds `.agents/skills/openspec-*/SKILL.md` for the six workflows used here (propose, explore, apply-change,
    update-change, sync-specs, archive-change), and `.agents/skills/.openspec-target`;
  - replaces each `.claude/skills/openspec-*/` directory with a link to its `.agents/skills/` copy;
  - **BREAKING** (for anyone typing them): deletes the six `/opsx:*` command files in `.claude/commands/opsx/`.
  The dry run lists no locally edited file to keep.
- **Name the 2.0 skills in CLAUDE.md.** Its workflow steps say `/opsx:propose`, `/opsx:apply` and `/opsx:archive`.
  They become `/openspec-propose`, `/openspec-apply-change` and `/openspec-archive-change`, the names the upgrade
  guide maps them to.
- **Name the skill in the `contributing` spec.** The scenario "A change is proposed" says an agent runs
  `/opsx:propose`; it becomes `/openspec-propose`. The requirement itself is unchanged.

Archived changes and `docs/superpowers/` keep the names they were written with. `scripts/guard.py` and
`.github/workflows/guard.yml` also say `/opsx:*`, and `guard.yml` pins CI's OpenSpec to 1.14.3, but both are
delivered from troupe-run/infrastructure, so they change there (troupe-run/infrastructure#308), which waits for this.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `contributing`: the scenario "A change is proposed" names the 2.0 skill, `/openspec-propose`, instead of the
  removed `/opsx:propose`.

## Impact

- Changed: `.agents/skills/` (7 files added), `.claude/skills/openspec-*` (6 directories become links),
  `.claude/commands/opsx/` (6 files deleted), `CLAUDE.md`, `openspec/specs/contributing/spec.md` (at archive).
- Unchanged: `openspec/config.yaml`, `.claude/settings.json` (delivered), the site and its tests.
- CI keeps validating with OpenSpec 1.14.3 until infrastructure#308 delivers the 2.0.0 pin. Its `openspec-strict`
  check reads only `openspec/`, whose format 2.0 doesn't change.
- Rollback: revert the commits.
