# Proposal

## Why

OpenSpec 1.14.3 was released on 2026-10-17, and this project's OpenSpec skills and commands were generated by 1.14.2
(troupe-run/website#16). The instructions that drive every change here should match the CLI that runs them, and
1.14.3 changes those instructions: propose and explore now check that a glob artifact's path stays inside the change
directory before anything writes it.

## What Changes

- Install OpenSpec 1.14.3 on the development machine through Homebrew (it's a global CLI; nothing in `package.json` or CI pins it).
- Run `openspec update` to regenerate the six skills under `.claude/skills/openspec-*/` and the six commands under
  `.claude/commands/opsx/`. Eight files change: all six skills move to `generatedBy: "1.14.3"`, and `propose` and
  `explore` (skill and command) gain the output-path check.
- The rest of 1.14.3 is CLI-only and needs nothing from this project: linked `spec.md` files, the `braces` audit
  warning gone, `validate --all` no longer hanging in hooks on a zero-column terminal, and very wide brace patterns
  rejected.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. This is tooling: no behaviour of the site, its checks or its documented contributing path changes, so the change
sets `skip_specs: true`.

## Impact

- `.claude/skills/openspec-*/SKILL.md` and `.claude/commands/opsx/*.md`: regenerated, not hand-edited.
- No site code, tests, CI or deploy change. `scripts/check-paths.toml` already skips `.claude/**`, so the check has
  no gate to run for these files.
- Out of scope: adding the extra workflows 1.14.3 offers (`new`, `continue`, `ff`, `bulk-archive`, `verify`,
  `onboard`). The project keeps its current profile.
