## How to read it

- A milestone is planned, not promised. The order can change, and so can what's in each one.
- A milestone gets a date when it's released. The rest have none.
- The issues behind each milestone are on [troupe's milestones](https://github.com/troupe-run/troupe/milestones) and
  the [roadmap board](https://github.com/orgs/troupe-run/projects/1).

This page changes as the plan does.
