## How to read it

- A release is planned, not promised. The order can change, and so can what's in each one.
- A release gets a date when it's out. The rest have none.
- The issues behind each release are on [troupe's milestones](https://github.com/troupe-run/troupe/milestones) and
  the [roadmap board](https://github.com/orgs/troupe-run/projects/1).

This page changes as the plan does.
